Configure Google Drive
  1. Enable the Google Drive API, the Google Sheets API, and the Google Picker API in the service-account project.
  2. Create an API key. Restrict it to the Google Picker API.
  3. Add no website restriction to the key. Campus Commander sends no referrer, so a website restriction blocks the Picker.
  4. Copy the project number from the project dashboard. The key file holds only the project ID.
  5. Add the Drive scope to domain-wide delegation, then check Google access.
